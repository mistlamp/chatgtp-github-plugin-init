# Using the Luna Chat Coder starter

This repository provides `AGENTS.md` and `.agents/skills/luna-chat-coder/` as a reusable AI-development protocol.

For a new project, use this repository as a template or copy these instruction files into the new repository. Then add the project's own source code, tests, build instructions, deployment configuration, and project-specific rules.

The protocol favors exact repository state, local/sandbox-first development, focused validation, deliberate use of GitHub Actions, diagnosis before CI retries, and durable recovery through Git commits and pull requests.

Project-specific instructions take precedence where they define the actual technology or workflow.
